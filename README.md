# codex-prime3

Projet web initialisé avec une page HTML simple, prêt à évoluer et à être publié avec GitHub Pages.

## Fichiers

- `index.html` : page d'accueil du projet
- `README.md` : présentation du dépôt

## GitHub Pages

Pour publier le site :
1. Ouvrir **Settings** du dépôt.
2. Aller dans **Pages**.
3. Dans **Build and deployment**, choisir **Deploy from a branch**.
4. Sélectionner la branche **main** et le dossier **/ (root)**.
5. Enregistrer.
